## uv Toolchain

1. To install uv package manager: `curl -LsSf https://astral.sh/uv/install.sh | sh`
    * *Alternatively, use: `pip install uv`*
2. Create a project: `uv init`
3. Create virtual environment: `uv venv`
4. Activate virtual environment: `source .venv/bin/activate`
5. Create `requirments.txt` file and add required packages
6. Run command to install packages: `uv add -r requirements.txt`
